# Neon Social Casino (Expo SDK 54)

Neon Social Casino is a **social casino** app built with **Expo SDK 54** and **React Native (JavaScript)**.

- European Roulette with inside & outside bets
- Blackjack vs dealer
- Wheel of Fortune bonus
- Daily bonus streak
- Coins & Gems (virtual currencies only)
- XP, levels, themes, avatars, achievements
- Local persistence with AsyncStorage

## Run

1. Install Node.js and Expo tooling.
2. In this folder run:

```bash
npm install
npx expo start
```

3. Open with the latest **Expo Go** (SDK 54 compatible) on iOS/Android.

> All currency is **virtual only**. No real-money gambling, no payouts, no real purchases.
